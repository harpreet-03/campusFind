# CampusFinder 📍  
**AI-Enabled Lost & Found Application for Campus Communities**

CampusFinder is an Android application designed to help students and staff efficiently report, discover, and recover lost or found items within a campus. The app combines AI-based image matching with secure in-app communication to ensure fast recovery while maintaining user privacy.

---

## 🚀 Features

- **Lost & Found Listings**  
  Post and browse lost or found items with images, descriptions, and location details.

- **AI-Based Image Matching**  
  Automatically identifies visually similar items using image similarity techniques to improve search accuracy.

- **Secure In-App Chat**  
  Enables direct communication between users without exposing personal phone numbers or email addresses.

- **Real-Time Updates**  
  Instantly reflects new posts and messages using cloud-backed data synchronization.

- **User-Friendly Interface**  
  Clean and intuitive UI designed following Android Material Design principles.

---

## 🛠 Tech Stack

- **Language:** Kotlin  
- **Platform:** Android SDK  
- **Architecture:** MVVM  
- **Backend & Database:** Firebase (Authentication, Firestore, Storage)  
- **AI / ML:** Image similarity matching  
- **Tools:** Git, GitHub, Android Studio  

---

## 🧠 How It Works

1. Users create a **Lost** or **Found** post with an image and item details.  
2. The system analyzes the uploaded image to find visually similar items.  
3. Matching results are shown to the user for quicker discovery.  
4. If a match is found, users can initiate a **secure in-app chat**.  
5. Items are recovered without sharing personal contact information.
